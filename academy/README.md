# Irenic Academy — isolated foundation (2026-10-31)

Status: **design and migration draft only; NOT deployed or approved for production**.

## Verified current system

- Repository: `krystal-CEO/Irenic-consulting-website`; production branch `main`.
- Existing site: hand-built static HTML generated by `scripts/build.mjs`, `src/site.mjs`, and `src/styles.css`. Cloudflare Worker serves `dist` assets and dispatches `/api/*` requests to `automation/worker.mjs`.
- Existing D1 binding `CONSULTING_DB` points to `irenic-consulting-inquiries`. **Do not place Academy records there.**
- Consulting direct-inquiry workflow is staged, not automatically activated. Preserve separate consulting email routing and inquiry handling.
- No Academy database, authentication, checkout, or learning service exists in the inspected repository.

## Proposed boundary

1. Public Academy course and verified jurisdiction-information pages at `irenicconsulting.com/academy/` (existing generator, no public claim of CE approval until verified).
2. Learner application at `learn.irenicconsulting.com` as a **separate Cloudflare Worker deployment**, with its **own** D1 database (`ACADEMY_DB`) and R2 private asset storage (`ACADEMY_PRIVATE`). This avoids changing the site's current Worker routing and minimizes rollback scope.
3. Use an established, maintained auth implementation compatible with Workers (evaluate Auth.js, Better Auth and third-party managed alternatives with release/security/support review before selection). Do not build password/crypto primitives from scratch. Explicitly test email-verification and recovery messages with a consulting-authorized transactional email sender.
4. Use hosted checkout and verified server-side Stripe events if Stripe consulting-account ownership is confirmed. Never reuse another entity's Stripe account. No live checkout without owner authorization.
5. Version all published curricula, quizzes and completion policies. Historical enrollment and certificate evidence must reference the actual published version; do not mutate completed records.
6. Admin requires MFA, role-scoped access, audit trail, and exports. Content must not be accessible on unprotected public object URLs.

## Cost and maintenance planning (not a quote)

Low-traffic Cloudflare Workers/D1/R2 can be inexpensive, but pricing depends on usage and plan; email delivery, streaming/captions, transactional payments, domains, backups and monitoring may add costs. Working range to budget, **not verified provider quotes:** approximately $0–$50/month at prototype scale and $25–$150+/month for a small production portal, plus per-sale processing fees and substantial implementation/security maintenance. Confirm official prices and quotas before any purchase. A custom portal is not maintenance-free.
